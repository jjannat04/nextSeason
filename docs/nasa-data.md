# NASA POWER — adapter reference

Current multi-source implementation: see [NASA DATA DEPTH](nasa-data-depth.md). The unified API and separate authenticated SMAP/IMERG adapters now coexist with the unchanged POWER adapter. The historical Milestone 1 notes below do not imply those adapters remain unimplemented.

Adapter: `backend/next_season/environment/power.py`. Official endpoint: [daily point API](https://power.larc.nasa.gov/docs/services/api/temporal/daily/).

Explicit request parameters: AG community, JSON, UTC, latitude/longitude, inclusive historical start/end, and `T2M,T2M_MIN,T2M_MAX,PRECTOTCORR`. Request period is limited to at most 366 past days. Credentials are not required for this POWER endpoint. SMAP and IMERG use separate authenticated asynchronous services, documented in the NASA data-depth report; they do not share this interface.

The provider verifies response parameter presence and units (temperature °C; precipitation mm/day), converts missing fill values to null, checks each expected date and reports per-parameter coverage. Partial temperature series cannot produce a supported comparison category. Regional source geometry/header/parameter metadata, raw response SHA-256, retrieval time, time standard, original query and normalized daily observations survive in the profile. Period rainfall is shown as a total, never labelled an irrigation requirement.

The exact-query cache key includes adapter version, all source parameters, coordinates and dates. A single private cache record stores raw response, query, retrieval date and checksum; writes are atomic. Corrupt/mismatched entries are not used. Closed historical intervals older than 30 days remain reusable; recent intervals refresh after seven days. A failed refresh/no valid cache returns 503 rather than a made-up or cross-location profile. Source reprocessing can require deliberate cache removal/refresh; this first adapter does not claim an automatic NASA version-change monitor. Precision is not increased by interpolating the NASA grid to a field measurement.

Current prototype comparison: complete historical daily-mean T2M ranges for activity calendar months versus source-checked global-species temperature envelopes; see the prototype and data-depth methods. It is a categorical reference check, not a locally calibrated suitability model, forecast or crop-stage heat injury estimate. Crops' broad absolute-envelope values do not automatically become hard environmental failure thresholds. No calibrated rainfall stress, water-demand or groundwater score is activated. Complete IMERG annual rainfall can supply a separately labelled global-reference screen; POWER precipitation is not silently substituted for IMERG.
